CONFIGURACIÓN DE LA API

Introduce la URL HTTPS de tu API desplegada por separado y pulsa GUARDAR Y CONECTAR. La dirección se guarda en este navegador y la clave solo durante la sesión.

¿Qué rutas debe tener mi API?
  • GET /distancia devuelve distancia, modo, motor y estado de conexión del Arduino.
  • POST /comando recibe { "accion": "izquierda" | "derecha" | "detener" }
  • POST /modo recibe { "modo": "manual" | "automatico" }
  • POST /estado recibe lecturas del Arduino, con la clave del dispositivo; responde { "comando": null } o una orden.
  • El panel usa x-admin-key; el Arduino usa x-api-key. No son intercambiables.
  • Si publicas web y API en dominios diferentes, configura CORS_ORIGINS.
